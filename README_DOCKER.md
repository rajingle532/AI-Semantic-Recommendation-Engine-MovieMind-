# 🐳 MovieMind AI - Docker Containerization Guide

Welcome to the **MovieMind AI** Docker Setup Guide! This project has been containerized using Docker and Docker Compose, allowing you to spin up the entire production-grade stack (React/Vite Frontend, FastAPI Backend, and MongoDB Database) with **a single command**.

---

## 🏗️ Architecture Overview

The multi-container architecture is organized as follows:

```
                  ┌──────────────────────────────────────────────┐
                  │                 USER BROWSER                 │
                  └──────────────────────┬───────────────────────┘
                                         │ Requests (Port 3000)
                                         ▼
                  ┌──────────────────────────────────────────────┐
                  │              frontend container              │
                  │   (Nginx Web Server / Static Vite SPA)       │
                  └──────┬────────────────────────────────┬──────┘
                         │                                │
        Static Files     │                                │ API Requests (/api/*)
        (index.html,     │                                │ (Proxied to backend)
        bundle, etc.)    ▼                                ▼
              ┌─────────────────────┐          ┌─────────────────────┐
              │    Local Browser    │          │  backend container  │
              │       Render        │          │    (FastAPI App)    │
              └─────────────────────┘          └──────────┬──────────┘
                                                          │
                                         Database Queries │ (Port 27017)
                                                          ▼
                                               ┌─────────────────────┐
                                               │  mongodb container  │
                                               │  (Persistent Data)  │
                                               └─────────────────────┘
```

1. **`frontend` (Nginx + React/Vite)**: Runs on port `3000`. Nginx acts as a high-performance web server, hosting static files and proxying all API requests starting with `/api` directly to the backend to eliminate CORS issues completely.
2. **`backend` (FastAPI)**: Runs on port `8000`. Serves recommendations, chatbots, auth, and filters. Bypasses TMDb/Sophos issues using offline circuit breakers.
3. **`mongodb` (MongoDB 7.0+)**: Runs on port `27017`. Persists watchlists, user profiles, and ratings using a persistent volume (`mongo_data`).

## 🚀 Quick Start (Run the Project)

### Step 1: Prepare your Configurations
Ensure that you have your environment variables set up in `backend/.env`. Docker Compose will automatically load key settings (like `TMDB_API_KEY`, `GEMINI_API_KEY`, etc.) directly from it.

### Step 2: Build & Start the Containers
Open a terminal in the root directory of the project (`d:\Desktop\moviemind-ai`) and run:

```bash
docker-compose up --build -d
```

* **`--build`**: Compiles the frontend assets and builds the Docker images.
* **`-d`**: Runs the containers in **detached mode** (in the background).

### Step 3: Access MovieMind AI
Once compilation completes, open your browser and navigate to:
👉 **[http://localhost:3000](http://localhost:3000)**

## 🛠️ Essential Docker Commands

Here is a list of commands to manage your containers:

### Check Status of Containers
See which services are currently running and check their ports:
```bash
docker-compose ps
```

### View Live Logs
To see logs generated by all services (great for debugging):
```bash
docker-compose logs -f
```

To see logs for a specific service (e.g., just the backend):
```bash
docker-compose logs -f backend
```

### Stop the Application
To stop the services and release the ports, run:
```bash
docker-compose down
```

### Wipe Persistent Database Data
If you ever need a fresh start and want to completely delete all saved data in MongoDB, stop the containers and delete the persistent volumes:
```bash
docker-compose down -v
```

## 📝 How Configuration Works

* **Dynamic DB Redirection**: Even if you have a remote `MONGODB_URI` specified in your `.env` file, the `docker-compose.yml` automatically overrides it for the container to point to our secure, local `mongodb` container (`mongodb://mongodb:27017/movie_recommender`), keeping your local operations clean and self-contained.
* **API Key Forwarding**: Secrets, JWT keys, and AI credentials are automatically passed from your `backend/.env` file straight into the backend container during startup.
